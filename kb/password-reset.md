# Resetting a password and two-factor authentication

## Password reset
Go to app.example.com/login, click "Forgot password", and enter the account email. The reset link expires after 30 minutes. Check the spam folder if it does not arrive within 5 minutes.

## Two-factor authentication
If the customer lost their 2FA device, they can use one of the backup codes shown when 2FA was enabled. Without backup codes, support must verify identity with the account owner's billing details before disabling 2FA. Never disable 2FA based on an email alone.
